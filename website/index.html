Capabilities

Honest about what an app‑level integration can do

Cisco publishes no embeddable AnyConnect SDK, so this module is a controller, not a tunnel. That boundary is where the design starts — and it is documented rather than papered over.

What it does

  • Connect and disconnect the installed Cisco Secure Client from your own UI.
  • Real results, not guesses. AnyConnect calls back on success or failure, and the module turns that into a typed event.
  • Full connection entries — protocol, IPsec auth mode, IKE identity, client certificates, iOS Connect On-Demand domains.
  • Profile, certificate and localization imports, plus availability and version detection.
  • Zero native config by hand. A config plugin writes the iOS query schemes and the Android manifest entries.

What it cannot do

  • No tunnel inside your app. That needs Cisco's partner SDK (NDA + licence) and Apple's packet-tunnel-provider entitlement.
  • No silent connections. AnyConnect shows its own UI, and Android gates it behind URI External Control.
  • No observing another app's tunnel on iOS. State is unknown there rather than a fabricated value.
  • No private APIs. Undocumented AIDL services and interface-sniffing tricks are deliberately out of scope.
  • No Expo Go. It ships native code, so a development build is required.

Typed end to end

Every option, event and error code is exported as a TypeScript type, with a stable code on failures.

Results you can trust

Callback URLs carry a token, so you can tie an outcome to the exact attempt that caused it.

Honest state

Observed on Android from the system VPN transport; explicitly unknown on iOS instead of invented.

Config plugin included

LSApplicationQueriesSchemes, the callback scheme, Android <queries> and the intent filter — written idempotently.

Swappable transport

The AnyConnectTransport seam lets you drop in a Cisco SDK or in-process tunnel without touching call sites.

Tested where it counts

The URI builders, the callback parser and the config plugin are covered by tests that run without a device.

Usage

Configure once, then treat it like any other API

Commands resolve as soon as the URI is handed to AnyConnect. The outcome arrives later as an event, exactly the way the platform works.

app/_layout.tsx 
import CiscoAnyConnect from 'expo-cisco-anyconnect';

// Configure once, as early as possible, so callback URLs are wired up.
CiscoAnyConnect.configure({ callbackScheme: 'myapp' });

if (await CiscoAnyConnect.isInstalled()) {
  const { url, token } = await CiscoAnyConnect.connect({
    name: 'Corp VPN',         // connection entry label
    host: 'vpn.example.com',  // FQDN, IP, or Group URL
  });

  console.log('dispatched', url); // outcome arrives via a callback
}
components/VpnStatus.tsx 
import { useState } from 'react';
import { Text } from 'react-native';
import { useAnyConnect, useAnyConnectCallback } from 'expo-cisco-anyconnect';

export function VpnStatus() {
  const { state, vpnTransportActive, anyConnectInstalled } = useAnyConnect();
  const [error, setError] = useState<string>();

  useAnyConnectCallback((event) => {
    if (event.action === 'connect' && event.result === 'error') {
      setError(event.error);
    }
  });

  return (
    <Text>
      {state} · transport {String(vpnTransportActive)} · installed{' '}
      {String(anyConnectInstalled)}
      {error ? ` · ${error}` : ''}
    </Text>
  );
}
screens/Vpn.tsx 
// connect() is fire-and-forget. AnyConnect opens its UI, and the outcome
// comes back later — through a URL the module routes into your app.
CiscoAnyConnect.addCallbackListener((event) => {
  if (event.result === 'success') {
    router.replace('/connected');
    return;
  }

  // The token ties a result to the request that caused it, so parallel
  // attempts stay distinguishable.
  console.warn(event.token, event.error);
});

await CiscoAnyConnect.connect({ host: 'vpn.example.com' });

Platforms

What each platform can actually report

The two operating systems expose different amounts of truth. Rather than flattening that into one unreliable value, the API tells you which is which — every state change carries its source.

Swipe horizontally to see every column →

State semantics. Column values describe what the module reports, not what it wishes it knew.
Signal Android iOS
state Observed — connected / disconnected from the system VPN transport unknown until a callback arrives, then real
vpnTransportActive true / false null — not observable for another app
anyConnectInstalled Resolved via PackageManager Resolved via canOpenURL
Connection results Callback URLs captured natively, including cold start Callback URLs via React Native Linking
App version Package metadata: version name and code Unavailable — another app's bundle is unreadable
Gating URI External Control must allow external URIs The user confirms the first hand-off

Supported actions and the URI each one produces.
Method URI Notes
createConnection anyconnect://create/?name=…&host=… Adds an entry without connecting.
connect anyconnect://connect/?host=… Appends onsuccess / onerror automatically.
disconnect anyconnect://disconnect onsuccess is Android-only for this action.
importProfile anyconnect://import/?type=profile&uri=… AnyConnect fetches the URL itself, from the device.
importCertificate anyconnect://import/?type=pkcs12&uri=… PKCS#12 bundles only.
localize anyconnect://import/?type=localization&… Pulls an anyconnect.po table from the gateway.
closeGui anyconnect://close iOS only; a no-op elsewhere.
